# 🛡️ SafeClick

> **Don't click blind. Scan it first.**  
> A lightweight, heuristic phishing detection engine designed specifically for the campus ecosystem.

## ⚠️ The Problem
Students are prime targets for social engineering. Scammers frequently use trusted channels (like class WhatsApp groups) to distribute fake fee reminders, hostel allocation links, and urgent notices. 

## 💡 The Solution
SafeClick is a real-time checkpoint. By analyzing the structural integrity of a URL and the psychological triggers in the accompanying message, it instantly flags high-risk threats. 

## 🚀 How to Run Locally
1. Clone this repository
2. Create a virtual environment: `python -m venv .venv`
3. Activate it and install dependencies: `pip install -r requirements.txt`
4. Start the server: `python app.py`
